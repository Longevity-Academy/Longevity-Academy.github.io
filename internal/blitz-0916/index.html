Method and limits

All event figures above are summed from every hourly bucket returned by the Longevity Life Academy store pixel (dataset 1440305917310328) for 15 Sep 2026, 23:07 IDT – 16 Sep 2026, 23:07 IDT. The per-group click table uses only events named OC_<slug>; these are the organic-link events requested for this report, and the slug-to-group/member mapping comes from the local tracking manifest. The generic OrganicClick event is not added to any group row.

One honest limitation. The pixel totals are not a controlled experiment and this report does not infer unique visitors, unique people reached, revenue, or causality. Posting state is read only from the local files that exist at run time; a missing state file is not treated as live. The organic-click events are event counts, not deduplicated users or sessions.
